# 检验科复核工作流

常规检验外包中转遇到周末与法定休息日，暂停审批还可能重复。科室不能用签发减接收的自然分钟直接判定常规违约，也不能把急诊跟普通标本套同一日历。

样例包含42条标准标本，脏台账加入重复签发、冲突签发、未知项目、错误急诊标志、缺失接收和时序倒置。000006标本从11月2日16:00到11月4日10:00，11月3日休息，工作分钟120；两条重叠批准暂停合并后仅扣30，净90。000030为急诊，同跨度按自然分钟2520减批准暂停30，净2490。

数据专员依次确认仪器来源、项目规则与工作日历，查看标本时效及暂停扣除证据，在异常隔离保留原始字段，按科室对账后签发批次复核。所有页面的数量均来自后端计算。

月末考核需按时锁定时效结果，而跨日补录常在复核后到达。工作台因此把“复核”与“定版”分开：复核确认本批核算，定版把统计截止前的标本冻结为正式结论。定版后补录窗口内后到的标本在下一次定版自动纳入并标注为补录已纳入；超出窗口的后到标本必须人工确认。时效计算页展示补录前后差异与每一条标本是否已进入正式结论，批次复核页保留每次定版的修订、超时名单与复核依据，恢复旧版时两版依据都仍可查。
